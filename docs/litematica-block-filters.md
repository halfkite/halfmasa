# 投影保存、删除与粘贴黑白名单

适用于本项目支持的全部 Minecraft 版本（1.21.1 至 26.3 的构建目标），需要安装对应版本的 Litematica。

在 halfmasa 配置的**其他模组扩展**栏中，分别开启“投影保存黑白名单”“投影删除黑白名单”或“投影粘贴黑白名单”。点击展开按钮编辑子选项，三项开关均可绑定快捷键，默认关闭，模式与名单各自独立。

| 模式 | 行为 | 空列表 |
|---|---|---|
| 黑名单（默认） | 排除名单中的方块 | 允许全部方块 |
| 白名单 | 只允许名单中的方块 | 不允许任何方块 |

黑名单和白名单分别保存，仅所选模式对应的列表生效。每行一个方块 ID，例如 `minecraft:stone`、`minecraft:chest` 或 `模组命名空间:方块名`。省略命名空间时按 `minecraft` 处理；不支持物品名称、通配符、标签或方块状态条件。

## 保存投影

从世界创建并保存投影时进行筛选，包括一次读取和分区读取。排除的方块在投影中变为空气，其方块实体数据、方块计划刻及流体计划刻也会排除。选区位置和尺寸保持不变，保存操作不改变世界方块。实体保存仍由 Litematica 自身设置决定。

例如：白名单填入 `minecraft:stone`，保存区域内只有石头保留，其余方块保存为空气。原生的忽略方块设置仍生效。

此项不会重新筛选已加载的投影文件、格式转换或单纯另存为操作；应重新从世界创建投影。

## 删除世界方块

使用 Litematica 的按投影删除或区域删除操作时，按**世界中的实际方块 ID**判断。不同方块状态使用相同 ID，例如各个方向的箱子均匹配 `minecraft:chest`。按投影删除时，原生删除模式和图层范围仍然生效。

单人直接删除和多人命令删除均会筛选。区域命令删除只为允许的连续方块生成命令，仍使用 Litematica 的命令队列及权限；大范围复杂筛选可能需要更多命令。黑名单中的箱子不会被删除，也不会清空内容。实体删除仍由 Litematica 的原有选项决定，不受方块名单控制。

## 粘贴投影

按**投影中的方块 ID**筛选粘贴内容，支持单人直接粘贴和多人命令粘贴，包括批量 `/fill`、WorldEdit 和方块实体数据处理。允许的方块仍遵循 Litematica 的替换模式、图层范围及 NBT 设置。

不允许的方块直接跳过，目标位置原有方块及容器内容保留；投影文件和显示内容不会改变，轻松放置与打印机放置不受此项控制。直接粘贴时，排除的方块所对应的方块/流体计划刻也不会导入。实体粘贴仍由 Litematica 自身设置决定。

例如：白名单仅填 `minecraft:stone`，只粘贴石头，其他位置保持原样。黑名单加入 `minecraft:air` 可避免投影中的空气清除世界方块；若投影包含 `minecraft:cave_air` 或 `minecraft:void_air`，须分别加入。

## 检查步骤

1. 放置石头、泥土和装有物品的箱子；保存白名单仅填 `minecraft:stone`，重新创建投影，确认仅石头保留且选区尺寸不变。
2. 删除黑名单填 `minecraft:chest`，分别执行按投影删除和区域删除，确认箱子及内容保留，其他符合原生删除条件的方块被删除。
3. 切换为空白名单，确认不删除方块；关闭筛选开关，确认恢复 Litematica 原生行为。
4. 粘贴白名单仅填 `minecraft:stone`，在已有泥土和装有物品的箱子处粘贴含石头、空气与箱子的投影，确认只粘贴石头，投影中被排除的箱子不会覆盖世界箱子或修改其内容。分别检查直接粘贴和命令粘贴的 `/setblock`、`/fill` 模式。
