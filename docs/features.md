# halfmasa 功能文档

> 文档版本：`1.6.1`
>
> 按 `X + H` 打开配置界面，也可以从 Mod Menu 进入。除特别说明外，功能默认关闭；热键为空表示默认不绑定按键。

## 投影相关功能

### 投影轻松放置自动补货 (litematicaAutoRefill)

开启后，仅当轻松放置所需物品在背包、快捷栏、副手及随身潜影盒内全部耗尽时，优先直接从无前后缀中文名假人按配置数量取货（默认 32，0 为半组），未找到有效且足量的来源后再按物品 ID 查询分类库存（直接取货需要新版 FGA `direct_take` 接口）；取货前再次检查本地材料，等待原版背包同步后重试原位置。

无频道、无权限、缺货或背包满时会提示并停止当前补货。取物结果不确定时暂停自动补货至重连，避免重复扣货。

- 分类: 其他模组扩展
- 类型: 带热键布尔值
- 默认值: *无快捷键*, `false`
- 模组约束:
  - 依赖模组:
    - Litematica (`litematica`)
    - Fabric API (`fabric`)
    - Fake Player API / FGA 服务端（库存 API v1）

另见：[设置与验收步骤](litematica-auto-refill.md)

### 投影补货取货数量 (litematicaRefillAmount)

从假人库存取货时每次取取的物品数量，0 表示半组（32）。轻松放置与打印机各自拥有独立的取货数量配置。

- 分类: 其他模组扩展
- 类型: 整数
- 默认值: `32`
- 最小值: `0`
- 最大值: `64`

### 投影补货静默取物 (litematicaRefillSilent)

需要新版 FGA `silent_take` 服务端接口，直接扣减已验证的离线来源库存，不召唤或下线假人。已经在线的来源保持在线；服务端不支持时提示并暂停补货。

- 分类: 其他模组扩展
- 类型: 带热键布尔值
- 默认值: *无快捷键*, `false`
- 模组约束:
  - 依赖模组:
    - Fake Player API / FGA 服务端（`silent_take` 接口）

### 投影打印机补货 (litematicaPrinterRefill)

打印机功能的自动补货，按 Hana 协调器或同系 InventoryUtils 实际方法接入；指定数量需更新 FGA 服务端。拥有允许从假人库存取货、取货数量和静默子选项，并支持折叠。

- 分类: 其他模组扩展
- 类型: 布尔值
- 默认值: `false`
- 模组约束:
  - 依赖模组:
    - Litematica (`litematica`)
    - Hana 协调器或兼容 InventoryUtils 的打印机模组

### 投影保存黑白名单 (litematicaSaveBlockFilter)

投影保存时按方块 ID 独立筛选，排除名单中的方块。

- 分类: 其他模组扩展
- 类型: 字符串列表
- 默认值: `[]`
- 模组约束:
  - 依赖模组:
    - Litematica (`litematica`)
    - Minecraft (`minecraft`) `>=1.21.1`

另见：[兼容范围与验收](litematica-block-filters.md)

### 投影删除黑白名单 (litematicaDeleteBlockFilter)

投影删除时按方块 ID 独立筛选。

- 分类: 其他模组扩展

- 模组约束:

### 投影粘贴黑白名单 (litematicaPasteBlockFilter)

- 模组约束:
  - 依赖模组:

## 其他模组扩展

### Xaero 路径点与单人存档绑定 (enableWorldBinding)

在默认 Windows 游戏目录的绝对路径 `C:\Users\<username>\AppData\Roaming\.minecraft\saves\<world>\config\halfmasa\xaero-world-binding.json` 保存 Xaero Minimap 与 World Map 的根目录 ID，使改名、移动和备份恢复后的存档继续使用同一路径点与地图数据；旧版 `C:\Users\<username>\AppData\Roaming\.minecraft\saves\<world>\.halfmasa-xaero-binding.json` 会自动迁移。

- 分类: 其他模组扩展
- 类型: 布尔值
- 默认值: `false`
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 导入路径点包 (importWaypointBundle)

自动识别剪贴板中的 `XWB1:`/`XWB2:` 文本或复制的第一个文本文件；旧 `XWB1` 导入当前维度，`XWB2` 保持原维度与分类。

导入 `XWB2:` 时按正式维度 ID、Xaero 等效维度 ID、完整容器节点和本地世界键逐级匹配，避免多个 VC 维度因共享 `waypoints` 节点而合并。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 导出全部维度路径点 (exportAllDimensions)

将当前 Xaero 世界根容器中的全部维度、全部分类导出为 `XWB2:` 文本或 UTF-8 `.txt` 文件；包括 VC 等模组创建的额外维度，不限于主世界、下界和末地。每个维度同时保存正式维度 ID、Xaero 等效维度 ID、完整容器节点、完整世界路径、本地世界键、Xaero 维度名和自定义名称。

文件导出默认命名为 `halfmasa-xaero-yyyyMMdd-HHmm.txt`，保存成功后同一内容也会复制到剪贴板。临时路径点、服务器路径点和第三方动态路径点不会进入分享包。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 导出当前维度路径点 (exportCurrentDimension)

将当前维度的全部分类导出为文本或文件。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 导出当前分类路径点 (exportCurrentWaypointSet)

将当前维度的当前分类导出为文本或文件。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 路径点去重 (dedupeWaypoints)

"合并当前"处理当前分类，"合并全部"分别处理本维度全部分类；按坐标和名称去重并保留较早的路径点。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### 路径点操作历史 (waypointHistory)

撤回或反撤回当前游戏会话内最近的导入与去重操作，最多保留 5 步；切换 Xaero 世界后清空。导入和去重操作会保存完整的 Xaero 路径点快照用于撤回，导出不会进入操作历史。

- 分类: 其他模组扩展
- 类型: 操作按钮
- 模组约束:
  - 依赖模组:
    - Xaero Minimap (`xaerominimap`)
    - Xaero World Map (`xaeroworldmap`)

### Conflux Map 扩展 (confluxMapExtensions)

需要匹配游戏版本及扩展 API 的 Conflux Map；打开路径点列表时可默认展示所有维度或公共路径点，传送后可关闭地图；未知高度的目标使用 `confluxMapUnknownHeight`（默认 `128`）传送；可在列表同时显示本地和共享路径点（左右或上下排列），并可用快捷键连续创建多个临时本地路径点（重进该世界后清除）。

- 分类: 其他模组扩展
- 类型: 布尔值
- 默认值: `false`
- 模组约束:
  - 依赖模组:
    - Conflux Map (`confluxmap`) 及扩展 API

### Conflux Map 未知高度传送目标 (confluxMapUnknownHeight)

使用 Conflux Map 扩展传送时，未知高度的目标使用的高度值。

- 分类: 其他模组扩展
- 类型: 整数
- 默认值: `128`
- 最小值: `-64`
- 最大值: `320`

### JEI/REI 查询历史 (itemManagerRecipeHistory)

为 JEI 和 REI 分别记录配方查询、用途查询和成功取得的物品。历史栏会在物品管理器首次打开时初始化，不需要先搜索配方。

默认 Windows 游戏目录下，查询历史保存在 `C:\Users\<username>\AppData\Roaming\.minecraft\config\halfmasa\search-history\`，JEI 与 REI 使用独立文件。

- 分类: 其他模组扩展
- 类型: 布尔值
- 默认值: `false`
- 模组约束:
  - 依赖模组:
    - JEI (`jei`) 或 REI (`roughlyenoughitems`)

### JEI/REI 查询历史行数 (itemManagerRecipeHistoryRows)

历史网格显示行数。

- 分类: 其他模组扩展
- 类型: 整数
- 默认值: `3`
- 最小值: `1`
- 最大值: `9`

### JEI/REI 查询历史位置 (itemManagerRecipeHistoryPosition)

将历史栏放在右下、右上、左上或左下，并让原生条目列表和收藏区避让。

- 分类: 其他模组扩展
- 类型: 选项列表
- 默认值: `bottom_right`
- 可用选项: `bottom_right`, `top_right`, `top_left`, `bottom_left`

### 循环切换 JEI/REI 查询历史位置 (cycleItemManagerRecipeHistoryPosition)

在四个角之间循环切换；物品栏打开时也可触发，并显示当前位置提示。

- 分类: 其他模组扩展
- 类型: 热键
- 默认值: *无快捷键*

阻止不安全的容器和潜影盒嵌套。

- 分类: 创造模式工具

- 默认值: `true`

### 创造搜索历史 (itemSearchHistory)

记录创造搜索后取得的物品，并在创造搜索结果顶部显示独立历史栏。

- 分类: 创造模式工具

### 创造搜索历史行数 (itemSearchHistoryRows)

创造搜索历史的最大显示行数。

- 分类: 创造模式工具
- 类型: 整数

- 最小值: `1`
- 最大值: `9`

### 搜索时显示创造历史 (itemSearchHistoryDuringSearch)

- 分类: 创造模式工具
- 类型: 布尔值
- 默认值: `false`

### Condensed 创造栏 (condensedCreative)

将附魔书、药水、药箭和多种方块变体合并为可展开的创造物品条目。

- 分类: 创造模式工具
- 类型: 布尔值
- 默认值: `false`

### 试炼栏 (trialCreativeTab)

在创造模式物品栏末尾新增「试炼栏」，收录全部试炼刷怪笼配置与试炼宝库，只在本模组的客户端可见。

- **安装对应版本 Fabric 创造栏 API 时**：按正常注册、内容重建和分页流程显示；开关变化会刷新页签缓存，关闭后隐藏。
- **未安装该可选 API 时**：使用创造物品栏右侧的「试炼栏」按钮打开，保持原版页签正常工作。

**收录内容：**

- **试炼刷怪笼**：全部 14 种原版试炼密室配置，每种包含三个条目——普通、不祥，以及进入冷却（cooldown）状态的版本，共 42 个条目。条目为携带方块实体数据的原版试炼刷怪笼，放置后即为对应的预设状态；冷却版本的 `cooldown_ends_at` 设为未来时间，放置后立即处于冷却中。
- **试炼宝库**：普通与不祥各一个条目，共 2 个条目。

**物品显示与模型：**

各支持版本的刷怪笼、试炼刷怪笼和宝库物品会按实际方块状态显示原版材质；刷怪笼物品还会显示内部生物，包括幼年和尺寸等数据。悬停说明显示笼子类型、内部生物、当前状态和试炼冷却状态。此效果也适用于携带数据的自然生成笼子，无需自定义名称。

创造模式使用 Ctrl＋中键复制时会保留源笼子的普通／不祥和状态属性；仅中键复制不含生物数据，无法还原其内部生物。未知自定义配置在客户端缺少定义时显示为未知。

界面图标直接使用对应状态的原版笼子材质，不叠加色条或染色。试炼栏中已配置的普通／不祥笼子使用原版「等待玩家」状态，冷却笼子使用冷却状态；自然复制的笼子保留源方块状态。界面中的生物模型正常直立、面向玩家，显示在笼子前景，史莱姆保持原尺寸，其他生物放大 20%。前景变换保持模型居中，避免被图标裁剪；手持、掉落物继续使用原版视角。

**覆盖的原版配置：**

`trial_chamber/breeze`、`melee/{husk,spider,zombie}`、`ranged/{poison_skeleton,skeleton,stray}`、`slow_ranged/{poison_skeleton,skeleton,stray}`、`small_melee/{baby_zombie,cave_spider,silverfish,slime}`。

> 注：1.21.1 尚未把试炼刷怪笼配置放入注册表，该版本直接读取原版自然生成密室结构中的内嵌配置，保留生物、装备、生成数量与奖励；1.21.3 起使用原版注册表配置。

- 分类: 创造模式工具
- 类型: 布尔值
- 默认值: `false`

## 客户端与界面功能

### 截图复制到剪贴板 (screenshotToClipboard)

- 分类: 客户端与界面功能
- 类型: 布尔值

在鞘翅提示中显示剩余飞行时间。

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

### 报告鞘翅剩余时间 (reportElytraTime)

在聊天栏报告当前装备鞘翅的预计剩余时间。

- 分类: 客户端与界面功能
- 类型: 热键
- 默认值: *无快捷键*

### 夜视平滑淡出 (nightVisionFade)

启用夜视平滑淡出；关闭后恢复原版结束前 10 秒闪烁。

- 分类: 客户端与界面功能
- 类型: 布尔值

### 夜视淡出秒数 (nightVisionFadeSeconds)

### 界面中移动 (inventoryMove)

原版背包和容器界面打开时继续移动、跳跃和潜行。

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

### 快速世界加载界面 (fastWorldLoadingScreen)

减少世界加载界面的额外等待。

- 分类: 客户端与界面功能
- 类型: 布尔值

### 快速资源包加载界面 (fastResourcePackLoadingScreen)

减少资源包加载界面的额外等待。

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

增强创造保存工具栏：支持拖入或替换单个物品、中键删除，并记住滚动位置；旧版游戏根目录 `hotbar.nbt` 首次自动复制到 `config/halfmasa/better-saved-hotbars/hotbar.nbt`。

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

### 冷却自动攻击 (cooldownAutoAttack)

按住攻击键时在原版攻击冷却完成后自动攻击准星目标。

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

### 可拖动列表 (draggableLists)

支持拖动资源包和服务器列表条目，并可隐藏原生移动箭头。

- 分类: 客户端与界面功能

- 分类: 客户端与界面功能
- 类型: 布尔值
- 默认值: `false`

### 快速滚动模式一开关 (fastScrollingPrimaryEnabled)

- 分类: 客户端与界面功能
- 类型: 布尔值

模式一的触发热键。

- 分类: 客户端与界面功能

### 虚空交易主开关

- 分类: 虚空交易
- 类型: 布尔值

## 输入与按键设置

### 更好的按键设置

"更好的按键设置"主项为默认开启的开关和打开界面的快捷键，原"打开按键映射浏览"快捷键会迁移到主项。

**子项配置：**

- "打开按键绑定界面"触发按钮及快捷键
- "按键绑定方式"
- "虚拟键盘布局"（104/122 键）
- "按键设置背景透明度"（0–100%，默认 31%，与原背景一致）

已移除原"允许直接按键改键""抬手确认""冲突按键逐项配置"和"重新加载冲突按键配置"入口。

**改键方式：**

- **默认虚拟按键**：先点击列表中的键位，再点击上方键盘选中，重复点击取消，预览按点击顺序用箭头连接；键位左侧的"确认"按钮应用预览，取消确认键位快捷键功能，Enter 可正常绑定。
- **机械按键模式**：按下键盘或鼠标生成预览，松开不自动确认，Esc 清空待确认键位，Backspace 可作为普通绑定键。

**界面布局：**

顶部保留改键方式和布局切换，布局与忽略按键编辑页共用，保存退出后同步到子配置。顶部除类别外按文字宽度收紧控件、空间不足时按顺序换行，键盘和列表随之下移。保存退出与不保存退出移到顶部，底部空间还给列表。所有改键、方式和布局先暂存；"保存退出"确认当前预览并保存，"不保存退出"仅在有改动时询问，取消或 Esc 返回继续编辑。

**按键浏览界面特性（所有支持版本）：**

本次游戏中默认记住列表位置、每个模组的折叠状态；104/122 键布局改为读取保存的子配置。键盘各行按统一边界对齐；折叠或展开时保留当前浏览位置。已绑定键位使用绿色底色，未绑定键位使用半透明灰色底色。蓝点标识原版绑定，橙点标识 MaLiLib 绑定，紫点标识组合键，三种小点沿键位右侧排列。原有浅红色单键冲突和深红色组合键冲突提示保留在相邻一列，可同时显示。122 键布局参考 PC/5250 终端键盘，增加 F13–F24 和六个终端组合键。

**列表操作（所有支持版本）：**

列表右侧使用"重置""以按键顺序触发""触发按键选项"列标题，后两列每行只显示"是/否"，不再打开详细设置页。单独的 Shift、Ctrl、Alt 和鼠标左中右键默认不触发选项，含修饰键的完整组合仍可触发；每项显式选择可以覆盖默认值。Fn 通常由键盘硬件处理，不会产生独立游戏按键事件。关闭触发选项不会禁用原热键。

所有改键和开关暂存在本界面，点击"保存退出"才写入原版和 MaLiLib 配置；有改动时"不保存退出"需要二次确认，取消或在确认页按 Esc 继续编辑；无改动直接退出。点击键盘筛选时，完整匹配或附加键最少的绑定先显示在"最匹配的按键"区，其余绑定按类别展示。进入或切换世界会清理轮盘会话状态，并剔除被菜单吞掉的松键记录，保留实际仍按住的键。顶部按钮使用半透明底色，类别菜单紧贴类别按钮下方展开；悬停提示在整页绘制后使用独立上层显示，长文字自动换行并限制在屏幕内。

**鼠标行为（所有支持版本）：**

未同时按住键盘按键时，鼠标左键、右键和中键不会自动触发冲突选择；攻击、放置和工具选区由原功能判断执行条件。带键盘按键的鼠标组合及鼠标侧键仍按原冲突规则处理。

- 分类: 输入与按键设置
- 类型: 带热键布尔值
- 默认值: `true`
- 模组约束:
  - 依赖模组:
    - Minecraft (`minecraft`) `>=1.21.1`

## 配置文件与数据路径

默认 Windows 游戏目录下，主配置文件为 `C:\Users\<username>\AppData\Roaming\.minecraft\config\halfmasa\halfmasa.json`。旧版根目录配置会迁移到 `C:\Users\<username>\AppData\Roaming\.minecraft\config\halfmasa\legacy\`。

功能数据使用临时文件和原子替换写入，避免正常保存过程中留下不完整 JSON。如果启动器使用自定义游戏目录，请将 `.minecraft` 替换为该绝对路径。

| 数据 | 路径（默认 Windows 游戏目录） |
|---|---|
| 主配置文件 | `config\halfmasa\halfmasa.json` |
| 旧版配置迁移 | `config\halfmasa\legacy\` |
| 快捷键圆盘数据 | `config\halfmasa\keybind-pie\bindings.json` |
| 服务器图标缓存 | `config\halfmasa\server-icons\` |
| JEI/REI 查询历史 | `config\halfmasa\search-history\` |
| Xaero 世界绑定 | `saves\<world>\config\halfmasa\xaero-world-binding.json` |
| 增强保存工具栏 | `config\halfmasa\better-saved-hotbars\hotbar.nbt` |

多人服务器相关的持久化数据统一保存在 `config\halfmasa\`，不会写入单人存档目录。
