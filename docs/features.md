# halfmasa 功能与配置

两项投影补货功能位于“其他模组扩展”栏：轻松放置与打印机各自拥有允许从假人库存取货、取货数量（默认32，0为半组）和静默子选项，并支持折叠。打印机按Hana协调器或同系InventoryUtils实际方法接入；指定数量需更新FGA服务端。[兼容范围与验收](litematica-auto-refill.md)

> 文档版本：`1.6.0`

Minecraft 26.3 新增[投影保存、删除与粘贴黑白名单](litematica-block-filters.md)，三组设置位于“其他模组扩展”栏，按方块 ID 独立筛选。

按 `X + H` 打开配置界面，也可以从 Mod Menu 进入。除特别说明外，功能默认关闭；热键为空表示默认不绑定按键。

### 试炼栏

开启 `trialCreativeTab` 后，创造模式物品栏会出现一个「试炼栏」，只在本模组的客户端可见。26.3 安装 Fabric 创造栏 API 时按正常注册、内容重建和分页流程显示；开关变化会刷新页签缓存，关闭后隐藏。未安装该可选 API 时，使用创造物品栏右侧的「试炼栏」按钮打开，保持原版页签正常工作。

- **试炼刷怪笼**：收录全部 14 种原版试炼密室配置，每种包含三个条目——普通、不祥，以及进入冷却（cooldown）状态的版本，共 42 个条目。
- 条目为携带方块实体数据的原版试炼刷怪笼，放置后即为对应的预设状态；冷却版本的 `cooldown_ends_at` 设为未来时间，放置后立即处于冷却中。
- **试炼宝库**：普通与不祥各一个条目，共 2 个条目。

26.3 的刷怪笼、试炼刷怪笼和宝库物品会按实际方块状态显示原版材质；刷怪笼物品还会显示内部生物，包括幼年和尺寸等数据。悬停说明显示笼子类型、内部生物、当前状态和试炼冷却状态。此效果也适用于携带数据的自然生成笼子，无需自定义名称；创造模式使用 Ctrl＋中键复制时会保留源笼子的普通／不祥和状态属性。仅中键复制不含生物数据，无法还原其内部生物。未知自定义配置在客户端缺少定义时显示为未知。

界面图标直接使用对应状态的原版笼子材质，不叠加色条或染色。试炼栏中已配置的普通／不祥笼子使用原版「等待玩家」状态，冷却笼子使用冷却状态；自然复制的笼子保留源方块状态。界面中的生物模型正常直立、面向玩家，显示在笼子前景，史莱姆保持原尺寸，其他生物放大 20%。前景变换保持模型居中，避免被图标裁剪；手持、掉落物继续使用原版视角。

条目覆盖的原版配置为 `trial_chamber/breeze`、`melee/{husk,spider,zombie}`、`ranged/{poison_skeleton,skeleton,stray}`、`slow_ranged/{poison_skeleton,skeleton,stray}`、`small_melee/{baby_zombie,cave_spider,silverfish,slime}`。

> 注：1.21.1 尚未把试炼刷怪笼配置放入注册表，该版本改用等价的内联配置对象实现相同效果。

## 客户端与界面功能

投影补货子选项 `litematicaRefillSilent`（“投影补货静默取物”）默认关闭，可绑定快捷键；需要新版 FGA `silent_take` 服务端接口，直接扣减已验证的离线来源库存，不召唤或下线假人。已经在线的来源保持在线；服务端不支持时提示并暂停补货。

所有支持版本提供 `litematicaAutoRefill`（投影轻松放置自动补货，默认关闭，可绑定快捷键）。开启后，仅当轻松放置所需物品在背包、快捷栏、副手及随身潜影盒内全部耗尽时，优先直接从无前后缀中文名假人按配置数量取货（默认32，0为半组），未找到有效且足量的来源后再按物品 ID 查询分类库存（直接取货需要新版 FGA direct_take 接口）；取货前再次检查本地材料，等待原版背包同步后重试原位置。客户端需要 Litematica 和 Fabric API，服务端需要支持库存 API v1 的 FGA；无频道、无权限、缺货或背包满时会提示并停止当前补货。取物结果不确定时暂停自动补货至重连，避免重复扣货。[设置与验收步骤](litematica-auto-refill.md)

## 虚空交易（扩展）

虚空交易主开关默认关闭。开启后，打开船只或矿车上的村民交易界面时，可按配置名称或自动识别同一载具上的假人并令其下线；关闭交易界面后默认执行 `rejoin`，也可改为等待 `spawn` 上线后再执行 `mount`。自动识别可能把载具上的真人玩家也当作假人，仅在确认载具上没有真人时使用。

村民消失或配置的假人全部下线后，自动交易由当前玩家在打开的村民交易界面中购买；启动后需保持界面打开。可填写从 1 开始的交易栏序号（例如 `1,2,3`），每一项买到材料不足；也可启用物品白名单，按交易产出物品 ID 筛选。交易后可选自动关闭面板或丢出本次获得的物品。自动打开村民界面支持独立的取消快捷键，默认 `Esc`。

材料准备选项可在交易前把绿宝石块拆成绿宝石，或通过 QuickShulker API 从随身潜影盒取出绿宝石和绿宝石块。材料准备需要客户端与服务端的 Fabric API，以及兼容的虚空交易服务端扩展；使用 QuickShulker 取物时服务端还需 QuickShulker。

## 输入、地图与实用功能

Minecraft 26.3 的“更好的按键设置”按键浏览界面会在本次游戏中默认记住列表位置、每个模组的折叠状态；104/122 键布局改为读取保存的子配置。键盘各行按统一边界对齐；折叠或展开时保留当前浏览位置；已绑定键位使用绿色底色，未绑定键位使用半透明灰色底色；蓝点标识原版绑定，橙点标识 MaLiLib 绑定，紫点标识组合键，三种小点沿键位右侧排列；原有浅红色单键冲突和深红色组合键冲突提示保留在相邻一列，可同时显示。122 键布局参考 PC/5250 终端键盘，增加 F13–F24 和六个终端组合键。“冲突按键选择”的子选项“冲突按键选择布局”可切换为条目模式：每项一行，列表过长时用滚轮滚动，松开触发键执行当前指向的条目。轮盘和条目模式会合并原版按键、MaLiLib（Masa）快捷键及自定义组合键的冲突项。组合键仅与按键完全相同的组合键构成冲突；已打开 X 的选择界面时继续按 C，会切换到 X+C 的冲突项。

26.3 的“冲突按键选择”配置使用适用于两种布局的名称；“选择界面透明度”是唯一背景透明度调整，0 完全透明、255 完全不透明，外框和滚动条也跟随该数值。标签内缩、外边距、文字阴影、模糊背景及颜色混合开关已移除。条目模式和轮盘模式共用基础颜色、选中颜色、高亮颜色、逐项自定义颜色、明暗交替与增亮量、大小、选中扩张、打开动画和压暗背景；条目模式的大小同时改变行高、文字与可见行数，绘制与点击范围使用同一布局。浅色选项自动使用深色文字。圆形精细度及中心取消区域仅用于轮盘模式；条目模式指向行外或行间空隙取消选择。配置 JSON 的现有字段名保持兼容，原有颜色和透明度数值继续使用。

26.3 中，未同时按住键盘按键时，鼠标左键、右键和中键不会自动触发冲突选择；攻击、放置和工具选区由原功能判断执行条件。带键盘按键的鼠标组合及鼠标侧键仍按原冲突规则处理。

26.3 的按键浏览列表右侧使用“重置”“以按键顺序触发”“触发按键选项”列标题，后两列每行只显示“是/否”，不再打开详细设置页。单独的 Shift、Ctrl、Alt 和鼠标左中右键默认不触发选项，含修饰键的完整组合仍可触发；每项显式选择可以覆盖默认值，Fn 通常由键盘硬件处理，不会产生独立游戏按键事件。关闭触发选项不会禁用原热键。所有改键和开关暂存在本界面，点击“保存退出”才写入原版和 MaLiLib 配置；有改动时“不保存退出”需要二次确认，取消或在确认页按 Esc 继续编辑；无改动直接退出。点击键盘筛选时，完整匹配或附加键最少的绑定先显示在“最匹配的按键”区，其余绑定按类别展示。进入或切换世界会清理轮盘会话状态，并剔除被菜单吞掉的松键记录，保留实际仍按住的键。顶部按钮使用半透明底色，类别菜单紧贴类别按钮下方展开；悬停提示在整页绘制后使用独立上层显示，长文字自动换行并限制在屏幕内。

26.3 的“更好的按键设置”主项为默认开启的开关和打开界面的快捷键，原“打开按键映射浏览”快捷键会迁移到主项。子项为“打开按键绑定界面”触发按钮及快捷键、“按键绑定方式”、“虚拟键盘布局”（104/122 键）和“按键设置背景透明度”（0–100%，默认 31%，与原背景一致），移除原“允许直接按键改键”“抬手确认”“冲突按键逐项配置”和“重新加载冲突按键配置”入口。默认使用虚拟按键：先点击列表中的键位，再点击上方键盘选中，重复点击取消，预览按点击顺序用箭头连接；键位左侧的“确认”按钮应用预览，取消确认键位快捷键功能，Enter 可正常绑定。机械按键模式按下键盘或鼠标生成预览，松开不自动确认，Esc 清空待确认键位，Backspace 可作为普通绑定键。顶部保留改键方式和布局切换，布局与忽略按键编辑页共用，保存退出后同步到子配置。顶部除类别外按文字宽度收紧控件、空间不足时按顺序换行，键盘和列表随之下移；保存退出与不保存退出移到顶部，底部空间还给列表。所有改键、方式和布局先暂存；“保存退出”确认当前预览并保存，“不保存退出”仅在有改动时询问，取消或 Esc 返回继续编辑。

“选择忽略按键”以按键名称显示当前列表，旁边的“虚拟按键”按钮打开独立编辑页。点击键位加入忽略，再次点击取消；支持原版与 MaLiLib 的键盘及鼠标绑定显示，并可切换 104/122 键布局。重置恢复 WASD、左右 Shift/Ctrl/Alt 和鼠标左中右键的默认忽略值；当前输入接口没有独立 Fn 键码；所有编辑先暂存，“保存退出”才写入配置，有改动时“不保存退出”需要确认，确认页按 Esc 返回，无改动或点击恢复原状态时直接退出。反转忽略规则开启时，该编辑页显示允许列表。两处虚拟键盘共用颜色：所有已绑定键位绿色，原版绑定有蓝点、MaLiLib 绑定有橙点、组合键有紫点，同时存在时保留所有小点；小点沿键位右侧排列，使用原冲突提示的矩形样式；浅红色单键冲突和深红色组合键冲突在相邻一列显示；“忽略冲突按键选择”使用灰点标识，保留原本的绿色或半透明灰色底色；六种标识点全部为 3×3，固定在右侧两列三行，缺失的状态留空，图例中的小点使用相同尺寸，未绑定按键半透明灰色，当前筛选使用金色边框。配置内部保留数字键码；26.3 会把旧默认列表更新为包含修饰键和鼠标键的新默认列表，并保持其他自定义列表。

## 已停用的高级功能

流体渲染屏蔽和实体渲染聚合位于“已停用功能”分类。它们可能显著改变画面或兼容性，因此不会进入推荐页，应在理解影响后单独启用和配置。

## 配置文件

默认 Windows 游戏目录下，主配置文件为绝对路径 `C:\Users\<username>\AppData\Roaming\.minecraft\config\halfmasa\halfmasa.json`。旧版根目录配置会迁移到 `C:\Users\<username>\AppData\Roaming\.minecraft\config\halfmasa\legacy\`。功能数据使用临时文件和原子替换写入，避免正常保存过程中留下不完整 JSON；如果启动器使用自定义游戏目录，请将 `.minecraft` 替换为该绝对路径。

26.3 新增 `classicPauseMenu`（经典暂停菜单，默认关闭）：主区恢复回到游戏、进度/统计、模组、选项/世界选项、保存退出的排列，附加图标和服务器按钮移到右侧；小窗口分列排列，保留原按钮动作、禁用状态和提示。
