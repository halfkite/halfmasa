## 使用

在 Masa 配置行点击星标收藏。halfmasa 独立的「更好的 Masa 功能收藏」展开后提供「打开 Masa 收藏界面」触发按钮与可绑定的快捷键；MaLiLib 原生右上角下拉菜单也保留，并增加独立的 Masa Favorites 入口。

星标不绘制按钮背景。收藏主开关默认开启，可绑定快捷键；「显示侧边收藏星标」默认开启，可独立隐藏原配置行星标。「收藏星标位置」提供「功能左侧／功能右侧」，默认功能右侧，修改后下一次客户端 UI tick 即应用到当前界面，无需重新打开。功能右侧紧邻重置按钮右侧，不固定在屏幕边缘。收藏置顶默认开启，仅作用于当前配置分类；halfmasa / Tweakeroo 的父子配置按组移动。收藏页本身按打开时的快照显示，不因取消收藏而删除或重排行。再次点击空心星可恢复；真正退出并重新打开后才更新成员。调整窗口、过滤和从子编辑器返回沿用本次会话。

编辑控件操作原配置对象。关闭收藏页或进入其他界面前，提交待处理文本，并按实际修改的模组调用其配置保存处理器、更新快捷键索引。收藏关系单独保存到 `config/halfmasa/masa-favorites.json`，不向其他模组的配置添加收藏字段。配置值仍由各模组保存到原文件。

页面滚动和搜索位置由现有 halfmasa 配置位置记忆功能处理，没有新增位置存储。

## 实现边界

- 在已安装的 halfmasa、MiniHUD、Litematica、Tweakeroo 的公开配置容器中发现对象，不要求先打开原配置页。
- 其他使用 MaLiLib 通用配置行的模组，可在访问原配置行时捕获对象；没有专用发现适配器的模组不保证启动后直接解析全部收藏。
- 稳定标识由模组 ID 与配置字段路径组成；布尔和快捷键 GUI 包装器映射回同一个底层对象。缺失模组的收藏记录保留，当前页面跳过无法解析的记录。
- 收藏文件带格式版本，先写临时文件再替换。保存失败时不改变收藏状态，星标提示失败并记录日志。损坏或不支持的新格式文件不会被空状态覆盖。
- 使用现有 Fabric / MaLiLib / Mixin 和 Gson，不新增运行时依赖。独立实现，未复制 MasaGadget 源码。
- 已接入仓库配置的 1.21.1～26.3 各构建目标；最终产物验证状态以同步报告为准。
