## 构建方式

使用项目 Gradle Wrapper，以 Java 25 启动 Gradle；1.21.x 使用 Java 21 编译，26.x 使用 Java 25 编译。逐版本执行（将 `<版本>` 替换为表中目标）：

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25.0.3'
.\gradlew.bat :<版本>:build -x test --offline --console=plain --max-workers=1 '-Dorg.gradle.java.installations.paths=D:\ai\carpet-fga\build\toolchains\jdk-21.0.12.1+1'
```

Java 21 路径仅作为已安装工具链读取，本轮没有修改 FGA 仓库。其他机器请换为本机 JDK 路径；首次下载依赖需要去掉 `--offline`。CI 已配置 Java 21 和 Java 25，按仓库提交的 `versions/mainProject` 选择预处理根。

## 适配范围与依赖

- 投影轻松放置补货、打印机补货、虚空交易、Conflux Map 扩展和相关配置/按键功能均进入公共客户端源码。按版本适配资源标识符、输入与界面 API、容器点击、网络频道以及船实体类型。
- 投影/打印机补货需要客户端 Fabric API，以及对应服务器提供的 FGA 库存协议。直接取货、静默和自定义数量需服务器提供相应频道；本轮没有移植或修改 FGA 服务端。
- Litematica 接入结构已静态核对本地 1.21.1 / 0.19.61、1.21.5 / 0.22.5、26.2 / 0.28.4、26.3 / 0.29.1 JAR；打印机按 Hana 协调器、通用库存检查或 ZXY 方法描述符选择适配。未知改版仍需要单独核对入口。
- 虚空交易假人命令需要服务端支持相应 player/rejoin 命令；自动准备绿宝石材料需要对应服务端频道。配套材料准备组件目前仅打包 26.3。
- Conflux Map 扩展需要匹配游戏版本并保持相应 API 的 Conflux Map。其他版本未安装对应 Conflux Map 进行游戏验收；双列表布局仍需实际界面验收。
- 物品渲染聚合等原有 26.3 专用渲染分支仍按版本保留；本轮客户端功能移植不意味着所有版本具有完全相同的渲染优化选项。

## 验收状态

本轮完成实际构建与 JAR 归档；未运行自动测试、未启动游戏或连接服务器。编译成功不能替代 Mixin 注入和游戏行为验收。

建议各目标实例人工检查：

1. 启动后检查扩展栏子项折叠、快捷键编辑和配置保存。
2. 对同一种投影材料连续补货至少两次，再切换另一种材料；检查数量、静默、缺货回退，以及关闭功能后的请求收尾。
3. 使用安装的打印机改版检查缺料补货、停止打印和收到材料后继续放置。
4. 打开载具村民交易界面，检查假人下线、指定交易项目、关闭面板后的 rejoin 或 spawn/mount。
5. 在对应 Conflux Map 中检查默认筛选、未知高度 Y=128、自定义高度、传送关闭地图和多个临时路径点重连清理。
