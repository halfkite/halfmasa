# 2026-10-06

## 试炼栏（Trial Creative Tab）— ds1 分支

在创造模式物品栏新增客户端合成页签「试炼栏」，集中存放全部原版怪的试炼刷怪笼
（普通/不祥/冷却态）与试炼宝库。已提交 ef8c2ec。

### 新增文件
- `feature/TrialCreativeItems.java`：条目数据构建。14 套配置（trial_chamber/breeze、
  melee/{husk,spider,zombie}、ranged/{poison_skeleton,skeleton,stray}、
  slow_ranged/{poison_skeleton,skeleton,stray}、
  small_melee/{baby_zombie,cave_spider,silverfish,slime}）× 3 状态 + 2 宝库 = 44 条目，缓存于 cachedItems。
- `feature/TrialCreativeTab.java`：页签单例。仅用 title+icon 构建（不用 displayItems 生成器，
  因 `CreativeModeTab.Output` 是 protected 无法在包外命名），内容由 mixin 填充。
- `mixin/TrialCreativeTabMixin.java`：注入 `CreativeModeTabs.tabs()`/`allTabs()` 的 RETURN，
  把合成页签追加到返回列表。
- `mixin/TrialCreativeTabContentsMixin.java`：注入 `CreativeModeTab.getDisplayItems()` HEAD，
  命中试炼页签时返回条目。

### 修改文件
- `config/Configs.java`：新增 `TRIAL_CREATIVE_TAB`（ConfigBooleanHotkeyed，默认 false），
  放在 CREATIVE_KEY 区块、GIVE_FULL_INVENTORY_EXPANDED 之后（注意前向引用）。
- `resources/halfmasa.mixins.json`：client 数组加入两个 Trial mixin。
- 语言文件 zh_cn/en_us：新增 config 键与 `halfmasa.creative_tab.trial`、
  `halfmasa.feature.trial_creative.*` 条目名。
- docs/features(.md/_en.md)、README(.md/_en.md) 相应更新。

### 关键技术分界（复用价值高）
- `normal_config`/`ominous_config`：1.21.1 为内联对象，1.21.3+ 为字符串 id
  （`//#if MC >= 1.21.3` 分支，低版本用 `fallbackConfig()` 造内联配置对象）。
- `DataComponents.BLOCK_ENTITY_DATA`：1.21.1–1.21.8 为 CustomData，1.21.10+ 为 TypedEntityData。
- `BlockEntityType.TRIAL_SPAWNER/VAULT` → 26.2 起迁移到 `BlockEntityTypes`。
- 试炼刷怪笼 NBT 键：normal_config/ominous_config/target_cooldown_length(36000)/
  required_player_range(14)/cooldown_ends_at/spawn_data。
